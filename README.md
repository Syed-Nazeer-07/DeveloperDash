# Developer Productivity Dashboard

A production-quality frontend application built for the Innovation Hacks Full Stack Development Internship.

## Features
- **Dashboard/Home Page**: A primary landing page with statistics.
- **Responsive Layout**: Sidebar and Top Navigation bar, adapting to mobile sizes.
- **Project & Task Management**: View active projects, task statuses, and team assignments.
- **Search & Filter**: Instantly search across projects and filter tasks by status and priority.
- **State Management**: Handled via Zustand.
- **Modern UI**: Designed with Tailwind CSS, Shadcn UI, and Lucide React icons, featuring a sleek dark mode toggle.

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Shadcn UI
- Zustand

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
